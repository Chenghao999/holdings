# 用户故事与用例（USER_STORIES）

## 用户故事

1. 作为 A 股散户，我希望把券商导出的历史对账单批量导入，以便不用手工逐条敲代码。
2. 作为基金定投用户，我希望在买入时记录手续费与托管费，以便成本核算真实反映费用。
3. 作为多账户用户，我希望用不同的组合（如「养老金」「压岁钱」）区分交易，以便分别追踪。

### 持仓与盈亏

4. 作为投资者，我希望查看当前持仓明细并按盈亏率排序，以便快速判断持仓表现。
5. 作为投资者，我希望看到累计费用支出（佣金、托管费）按标的汇总，以便了解真实成本。

### 价格同步

6. 作为用户，我希望一键同步所有资产最新价格，以便获得实时市值。
7. 作为用户，我希望在数据源不可用时自动降级，以便价格同步尽量不中断。

### 报表与回溯

8. 作为定投用户，我希望每月记录资产快照，以便看到资产净值曲线。

### 维护

10. 作为用户，我希望删除误录的交易记录，以便保持数据准确。

## 关键用例流程

### 用例 1：导入券商对账单

- 前置条件：已运行 `holdings init`，手头有导出的 CSV 文件。
- 主流程：用户执行 `holdings import --file trades.csv --group 养老金 --fee-column 手续费`。
- 结果：交易（含费用）写入 `transactions` 表，可按组合区分。

### 用例 2：记录一笔基金托管费

- 主流程：用户执行 `holdings add --symbol 518880 --market A股 --type FEE --qty 0 --price 0 --fee 12.5 --notes "4月托管费"`。
- 结果：该笔交易记录为 `trade_type='FEE'`，不改变持仓数量与成本，仅汇总为费用支出。

### 用例 3：同步价格并生成报表

- 主流程：用户先执行 `holdings sync --market 全部`，再执行 `holdings report --verbose`。
- 结果：终端显示持仓表格、配置占比柱状图与费用汇总。
