# 常见问题（FAQ）

## 数据同步

### Q：akshare 报错 `ConnectionError` 怎么办？

A：这是网络或数据源波动导致的。A 股会按 `sync.retry_count` 重试（默认 1 次），失败后降级至 yfinance；若彻底失败会以退出码 `1` 提示「数据源不可用」。可检查网络后重试。

> **可调项**：`sync.retry_count`（每个数据源各自的重试次数）、
> `sync.timeout_seconds`（每个标的的等待上限，`0` 表示不限）、
> `cache_ttl_seconds`（缓存有效期）、`data_sources.priority`（各市场按什么顺序
> 尝试数据源）均已生效。唯一例外是黄金——它的两个源是两种不同的标的，
> 由代码选路，配置里的 `黄金:` 一项会被忽略（见 [CONFIG_SPEC](CONFIG_SPEC.md)）。

### Q：同一标的多久同步一次价格？

A：默认 5 分钟内同一标的直接返回本地缓存，不重复请求，防止被封禁。可通过 `cache_ttl_seconds` 调整。

## 数据与迁移

### Q：如何把数据库迁移到另一台电脑？

A：直接拷贝 `data/holdings.db` 到新电脑对应目录即可。数据为单文件 SQLite，无需额外导出导入。

### Q：如何备份我的数据？

A：备份 `data/holdings.db`（交易与快照）以及 `config.yaml`（配置）两份文件即可。

## 费用与成本

### Q：手续费 / 佣金怎么记录？

A：买入时在 `add` 中加 `--fee 5.0`，费用会计入持仓成本。CSV 导入时用 `--fee-column` 指定费用列。

### Q：基金托管费 / 管理费怎么记？

A：使用 `trade_type=FEE` 记录：

```bash
holdings add --symbol 518880 --market A股 --type FEE --qty 0 --price 0 --fee 12.5 --notes "4月托管费"
```

FEE 类型不改变持仓数量与成本，仅在报表中单独汇总费用。

### Q：对账单里的分红 / 送股为什么没有导入？

A：这几类行**不入账，但会逐行报出来**，导入结束时你能看到它们在第几行、为什么不入账：

```text
识别 6 行，入账 1 笔，未入账 5 行
  第 3 行 分红派息，未入账：分红如何摊销成本尚未支持（见 BACKLOG B-23）
```

分红、送转、配股会改变数量或成本价，口径尚未支持（[B-23](BACKLOG.md#b-23)）；
银证转账与利息动的是现金，与持仓无关。它们目前都不进账本——**不会**被算成
「已导入」，也不是被静默丢掉了。

想让这种情况直接失败（比如写脚本时），加 `--strict`：有未入账的行就一笔都不写、
退出码 5。其余取值认不出的行（既不是 `BUY`/`SELL`/`FEE`，也不在上面这张表里）
一律整批拒绝，需要你先改文件。

### Q：同一份对账单导了两遍，账会翻倍吗？

A：不会。`import` 落库前会查重，发现有已经记过的行就**报出行号、一笔不写**、
退出码 `5`——默认不是静默跳过，因为被跳过的那一笔可能正是你要的：

```text
  第 2 行重复：与库里已有的 #1 是同一笔——600519 2025-01-02 BUY 100 @ 1500
错误（5）：1 行与已有记录重复（第 2 行），未写入任何数据
```

逐月补充导出（本月文件含上月最后几笔）是常事，用 `--dedupe skip` 跳过重复的、
只写新的。判重按券商流水号（标准 CSV 的 `external_id` 列），没有则按
「标的 + 日期 + 类型 + 数量 + 价格 + 费用」的全字段指纹。

> 指纹分不开「同一天分两次、同价同费各买 100 股」这种**真实的两笔成交**，
> 会把它报成重复。确认是两笔就加 `--dedupe off` 原样全写。

### Q：导入报「认不出这份对账单的格式」怎么办？

A：说明表头对不上任何已注册的格式。目前只有标准 CSV（英文列名）与两个
**示例**格式，真实券商的解析器还在等真实样本（[B-30](BACKLOG.md#b-30)）。
工具宁可报错也不猜一个最像的——猜错的代价是整批数字错，而你会以为导成功了。

导入时印的「解析格式：…」会告诉你它认成了哪家；要明写就用 `--broker`
（可选值在报错里列着）。要接自己的券商：照
`src/holdings/data/brokers/demo_a.py` 加一个模块、在注册表里加一行即可，
命令行的代码一行都不用改。格式清单见 [USER_GUIDE](USER_GUIDE.md) 第 5 节。

**编码不用先转**：UTF-8（含 BOM）、GB18030 / GBK、UTF-16 都能直接读，
Windows 上 Excel 另存为出来的 GBK 文件直接导即可。

### Q：卖出的成本怎么算？

A：采用移动加权平均法，卖出时数量减少但成本价保持不变，符合国内多数券商展示逻辑。

## 市场与标的

### Q：支持哪些市场？

A：A 股、美股、黄金。黄金优先国内现货 / 黄金 ETF（`518880`），降级至 `GC=F` 国际黄金。

### Q：找不到我的标的怎么办？

A：检查代码与市场是否匹配，程序会以退出码 `2` 提示「未找到该标的」。若仍无法识别，可在 `data/` 层扩展对应数据源。

## 其他

### Q：是否支持自动下单交易？

A：不支持。本工具只做记账与追踪，不接券商下单接口。
