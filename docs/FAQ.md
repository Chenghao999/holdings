# 常见问题（FAQ）

## 数据同步

### Q：akshare 报错 `ConnectionError` 怎么办？

A：这是网络或数据源波动导致的。A 股会按 `sync.retry_count` 重试（默认 1 次），失败后降级至 yfinance；若彻底失败会以退出码 `1` 提示「数据源不可用」。可检查网络后重试。

> **可调项**：`sync.retry_count`（每个数据源各自的重试次数）、
> `sync.timeout_seconds`（每个标的的等待上限，`0` 表示不限）、
> `cache_ttl_seconds`（缓存有效期）、`data_sources.priority`（各市场按什么顺序
> 尝试数据源）均已生效。唯一例外是黄金——它的两个源是两种不同的标的，
> 由代码选路，配置里的 `黄金:` 一项会被忽略（见 [CONFIG_SPEC](CONFIG_SPEC.md)）。

### Q：同一标的多久同步一次价格？

A：默认 5 分钟内同一标的直接返回本地缓存，不重复请求，防止被封禁。可通过 `cache_ttl_seconds` 调整。

## 数据与迁移

### Q：如何把数据库迁移到另一台电脑？

A：直接拷贝 `data/holdings.db` 到新电脑对应目录即可。数据为单文件 SQLite，无需额外导出导入。

### Q：如何备份我的数据？

A：备份 `data/holdings.db`（交易与快照）以及 `config.yaml`（配置）两份文件即可。

## 费用与成本

### Q：手续费 / 佣金怎么记录？

A：买入时在 `add` 中加 `--fee 5.0`，费用会计入持仓成本。CSV 导入时用 `--fee-column` 指定费用列。

### Q：基金托管费 / 管理费怎么记？

A：使用 `trade_type=FEE` 记录：

```bash
holdings add --symbol 518880 --market A股 --type FEE --qty 0 --price 0 --fee 12.5 --notes "4月托管费"
```

FEE 类型不改变持仓数量与成本，仅在报表中单独汇总费用。

### Q：卖出的成本怎么算？

A：采用移动加权平均法，卖出时数量减少但成本价保持不变，符合国内多数券商展示逻辑。

## 市场与标的

### Q：支持哪些市场？

A：A 股、美股、黄金。黄金优先国内现货 / 黄金 ETF（`518880`），降级至 `GC=F` 国际黄金。

### Q：找不到我的标的怎么办？

A：检查代码与市场是否匹配，程序会以退出码 `2` 提示「未找到该标的」。若仍无法识别，可在 `data/` 层扩展对应数据源。

## 其他

### Q：是否支持自动下单交易？

A：不支持。本工具只做记账与追踪，不接券商下单接口。
